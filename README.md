# Friendspartytime

Quick browser game prototype with a new **Samurai Gun Arena** mode:

- Main menu entry to launch the arena fighter
- Character select with multiple shape-based fighters
- 1v1 side-view arena combat with:
  - Light and heavy attacks
  - Smash-style stocks (5 stocks each)
  - Knockback scaling with damage
  - Dynamic camera zoom and shake polish

## Run locally

Open `index.html` in a browser.
